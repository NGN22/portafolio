# Mi Portafolio

  

Aplicación web desarrollada con Angular 20 y Angular Material.  

  

---  

  

##  Características  

  

-  Tema dinámico (Light / Dark) con detección del sistema  
-  Signals   
-  Componentes standalone  
-  Iconos SVG personalizados registrados en Angular Material  
-  Arquitectura modular   
-  Responsive
  

---  

  

##  Tecnologías utilizadas  

  

- Angular 20  
- Angular Material (Material 3)  
- TypeScript  
- SCSS  
- HTML5
